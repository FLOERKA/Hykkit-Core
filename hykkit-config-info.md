## Wiki по hykkit.yml

    online-mode: false
    players-collisions: true
    port: 5520
    quic-algorithm-type: BBR
    transport-type: QUIC

Построчно:
**online-mode: false**
Позволяет настроить режим пиратского сервера по типу серверов Minecraft. 
false - выключено, зайти могут только с лицензии или, если это singleplayer сервер, только один человек. 
true - зайти могут как те, у кого есть лицензия, так и те, кто её не имеет.

**players-collisions: true (experimental)**
Изменение столкновений игроков друг с другом.
true - игроки не могут проходить через друг друга.
false - игроки могут проходить через друг друга

**port: 5520**
Изменение стандартного порта сервера, чтобы не использовать изменение в запускаторе

**transport-type: QUIC**
Изменение протокола передачи.
TCP - стандартный транспортный протокол, используемый на серверах Minecraft. Обеспечивает надежную передачу пакетов без потерь.
QUIC - современный протокол от Google, который пытается взять лучшее от TCP и UDP сразу. Обеспечивает доставку пакетов, но пытается лучше работать с потерями, в отличие от TCP.

**quic-algorithm-type: BBR**
Изменение алгоритма работы с перегрузкой пакетов.
BBR - используется в последней версии Hytale.
CUBIC - использовался в прошлых версиях Hytale
RENO - Старый алгоритм, который сейчас практически не используется.
